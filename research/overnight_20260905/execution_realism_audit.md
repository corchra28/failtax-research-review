# Audit de realism al executiei (fara PnL nou)
- Taxe: bps observate din evenimente la starea de intrare/iesire; evenimentele cu taxa 0 (2.322 in banda) nu sunt copiate — se cere tierul demonstrat de evenimentele vecine (4 pool-uri excluse: FEE_UNRESOLVED). Tabelul de tiere are 30–125 bps; noncanonical 25/5/0 (21,9 M evenimente observate).
- Rent/ATA: contul de token asociat (≈ 0,00204 SOL) este recuperabil la inchidere; nu este inclus in PnL (cost de capital, nu de tranzactie). Semnatura 5.000 + prioritate 100.000 lamports per tx, 2 tx = 0,00021 SOL; Jito/MEV si esecul de includere NU sunt modelate (FRICTION = INCOMPLETE_UPPER_BOUND).
- Incertitudine intra-slot: fara transactionIndex in banda prospectiva; intrarea/iesirea se executa pe starea de dupa toate evenimentele cu ts <= X (secunda intreaga), adica scenariul defavorabil; starile neancorate (cozi, pre-ruptura) si rupturile de lant in perioada de detinere sunt excluse (52 + 2 pool-uri).
- Overlay directional: tranzactiile ulterioare ale altora sunt aplicate pe rezervele observate, nu pe cele modificate de pozitia noastra; la 0,25 SOL intr-un pool de ~67 SOL impactul este ~0,4 %, iar eroarea counterfactuala este de ordinul 2, dar nenula.
- Exact-B: cumpararea exact-B sub bugetul de 0,25 SOL (semantica standard PumpSwap) si vanzarea aceluiasi B; niciun inventar rezidual.
- Latenta: +2 s testat ca stres; decizia foloseste doar evenimente cu ts < D (secunda intreaga), deci exista o latenta implicita de pana la 1 s in favoarea noastra la nivelul rezolutiei ts; cazul conservator este acoperit de intrarea „dupa toate evenimentele cu ts <= D".
